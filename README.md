# ⚖️ Chibuchi Ovunda — Virtual Legal Assistant & Practice Operations

A dynamic, high-performance, editorial web portfolio designed for **Chibuchi Ovunda**, an elite Virtual Legal Assistant providing strategic administration, court-ready document formatting, calendar orchestration, and confidential client communication for attorneys and law firms.

Live Preview: [https://chibuchi-ovunda.vercel.app/](https://chibuchi-ovunda.vercel.app/)

---

## ✨ Dynamic Motion & Interactive Features

- **Smooth Staggered Scroll Reveals**: Fluid hero entrance, luxury typography, character staggers, and micro-interactions.
- **Double Infinite Marquee Tickers**: Smooth 60fps marquee showcasing legal competencies, court-ready proficiencies, and NDA protections.
- **Dynamic Live Metrics**: Real-time animated counters displaying On-Time Filing Rate, Documents Processed, and Response SLAs.
- **Interactive Services Matrix**: 3D tilt cards, expandable deliverable drawers, and quick "Request Service" action triggers.
- **Case Study Lightbox Showcase**: Filterable gallery (Case Organization, Court Filings, Client Ops, Scheduling) with fullscreen inspection modal.
- **Interactive Legal Tech Stack**: Deep-dive tool inspector for Microsoft 365, Google Workspace, Clio, Dropbox, Canva, and DocuSign.
- **Consultation & Direct Booking Builder**: Interactive multi-select service tags, urgency selectors, one-click email copy with toast feedback, and confetti celebration on inquiry creation.
- **Glassmorphic Sticky Navigation**: Dynamic scroll progress bar, live availability indicator, and smooth mobile sliding drawer.

## 🛠️ Tech Stack & Architecture

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite 6](https://vitejs.dev/)
- **Styling**: [TailwindCSS 3](https://tailwindcss.com/)
- **Motion & Physics**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Celebration Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Playfair Display (Serif), Cinzel (Display), Plus Jakarta Sans (Body)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Visit `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```
The compiled and optimized production files will be output to `dist/`.

## 📦 How to Push to GitHub & Deploy to Vercel

### Step 1: Create a new repository on GitHub
1. Go to [github.com/new](https://github.com/new).
2. Name your repository (e.g. `chibuchi-ovunda-portfolio`).
3. Leave it **Public** or **Private**, do **not** check "Add a README file".
4. Click **Create repository**.

### Step 2: Push this local repository to GitHub
Run the following commands in your terminal:
```bash
git init
git add .
git commit -m "feat: complete dynamic motion redesign with tickers, lightboxes & consultation builder"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/chibuchi-ovunda-portfolio.git
git push -u origin main
```

### Step 3: Deploy on Vercel
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New... -> Project**.
3. Import your `chibuchi-ovunda-portfolio` repository.
4. Framework Preset will auto-detect as **Vite**.
5. Click **Deploy** — your live dynamic site will be ready in under 30 seconds!
